# 技术架构

## 分层

```txt
UI Layer        场景、按钮、卡牌视图、敌人视图
Controller      BattleController / MapController
Domain          BattleState / CardInstance / EnemyInstance
System          EffectResolver / StatusManager / EnemyAI
Data            JSON + DataLoader + Library
```

## 关键原则

- 卡牌效果数据驱动。
- 战斗状态集中在 BattleState。
- UI 只读状态并触发命令，不直接改血量、格挡、状态。
- 所有复杂效果先抽象为 effect type。
