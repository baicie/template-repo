# 快速开始

本文档帮助你从零启动并运行镇妖司项目。

## 环境要求

| 依赖 | 版本要求 | 说明 |
|------|---------|------|
| Godot 编辑器 | **4.2+** | 从 [godotengine.org](https://godotengine.org) 下载 |
| Python | 3.10+ | 用于运行数据验证脚本 |
| Pytest | 最新版 | `pip install pytest jsonschema` |
| Git | 任意版本 | 用于版本控制 |

> **注意**：不需要安装 GPU 或图形驱动，Godot 引擎在 CI 中以 `--headless` 无头模式运行。

## 1. 下载并安装 Godot 编辑器

### 方式一：官网下载（推荐）

1. 访问 [https://godotengine.org](https://godotengine.org)
2. 下载 **Godot 4.2.x**（推荐 4.2.2）
3. Linux/macOS：将下载的二进制文件添加到 PATH 或放在项目目录外
4. Windows：下载 `.exe` 版本

### 方式二：Steam（仅限 Windows/macOS）

在 Steam 商店搜索 "Godot 4"，安装后右键 → 属性 → 勾选 "启动选项" 填入 `--path .`

### 方式三：命令行安装（Linux/macOS）

```bash
# 下载 Godot 4.2.2 Linux 64-bit
wget https://github.com/godotengine/godot/releases/download/4.2.2-stable/Godot_v4.2.2-stable_linux.x86_64.zip
unzip Godot_v4.2.2-stable_linux.x86_64.zip
chmod +x Godot_v4.2.2-stable_linux.x86_64
mv Godot_v4.2.2-stable_linux.x86_64 /usr/local/bin/godot

# 下载 Godot 导出模板（必须）
mkdir -p ~/.local/share/godot/export_templates/4.2.2.stable
wget https://github.com/godotengine/godot/releases/download/4.2.2-stable/Godot_v4.2.2-stable_export_templates.tpz
mv Godot_v4.2.2-stable_export_templates.tpz ~/.local/share/godot/export_templates/4.2.2.stable.zip
cd ~/.local/share/godot/export_templates/4.2.2.stable && unzip ../4.2.2.stable.zip
```

## 2. 克隆项目

```bash
git clone https://github.com/你的用户名/zhenyaosi.git
cd zhenyaosi
```

## 3. 用 Godot 编辑器打开项目

### 图形界面方式

1. 启动 Godot 编辑器
2. 点击右侧 **导入（Import）**
3. 选择项目根目录下的 `project.godot` 文件
4. 点击 **导入并编辑**

> 首次打开时，Godot 会扫描并导入所有资源（约 10-30 秒）。

### 命令行方式（无 GUI）

```bash
# 以无头模式导入资源（CI 用）
godot --headless --import

# 直接运行主场景
godot --headless --path . --editor  # 启动编辑器（需要 GUI）
```

## 4. 运行游戏

在 Godot 编辑器中：

1. 按 **F5** 或点击右上角 ▶️ **运行** 按钮
2. 游戏窗口将打开，显示主菜单
3. 点击 **Start Test Battle** 进入测试战斗

### 键盘操作

| 按键 | 功能 |
|------|------|
| **鼠标左键** | 点击卡牌并拖拽到敌人身上出牌 |
| **E** 或 **End** | 结束当前回合 |

## 5. 运行数据验证

每次修改卡牌或敌人数据后，建议运行验证：

```bash
cd tools
pip install pytest jsonschema   # 首次需要安装
python -m pytest validate_json.py -v
```

正常输出示例：

```
tools/validate_json.py::TestCards::test_cards_is_list PASSED
tools/validate_json.py::TestCards::test_card_has_required_fields PASSED
tools/validate_json.py::TestCards::test_card_validates_against_schema PASSED
tools/validate_json.py::TestEnemies::test_enemies_is_list PASSED
tools/validate_json.py::TestEnemies::test_enemy_has_required_fields PASSED
tools/validate_json.py::TestEnemies::test_enemy_validates_against_schema PASSED
```

## 6. 导出游戏

### 导出模板配置

首次导出前，需要安装导出模板：

1. Godot 编辑器 → **编辑器（Editor）** → **管理导出模板（Manage Export Templates）**
2. 输入版本号：`4.2.2.stable`
3. 下载并安装

### 导出 Linux 二进制

```bash
# 确保已安装导出模板
godot --headless --export-release "Linux/X11" builds/linux/zhenyaosi.x86_64
```

### 导出 Web 版本

```bash
godot --headless --export-release "Web" builds/web/index.html
```

## 7. CI/CD 工作流

项目配置了 GitHub Actions（`.github/workflows/validate.yml`），每次 push 自动运行：

| Job | 说明 |
|-----|------|
| `validate-json` | 验证 JSON 数据符合 Schema |
| `python-tests` | 运行 Python 单元测试 |
| `godot-import` | Godot 无头导入检查 |
| `export-smoke` | 导出 PCK 冒烟测试 |

## 常见问题

### Q: 导入时报错 "Resource not found"

确保用 Godot 4.2.x 打开项目，版本不匹配会导致资源无法识别。

### Q: 导出时报错 "Export template not found"

需要在编辑器中配置导出模板：编辑器 → 管理导出模板 → 填入 `4.2.2.stable` → 下载。

### Q: 数据验证失败

检查 `resources/data/cards.json` 或 `resources/data/enemies.json` 中是否有 JSON 语法错误（逗号、引号、缺少必填字段等）。可以粘贴到 [jsonformatter.org](https://jsonformatter.org) 进行格式化检查。

### Q: 找不到 `scripts/` 目录

项目使用 GDScript，所有脚本位于 `scripts/` 目录。确保 `project.godot` 中的 `[autoload]` 配置指向了正确的路径。

### Q: 如何添加新卡牌

1. 编辑 `resources/data/cards.json`，参考现有卡牌格式
2. 运行 `python -m pytest tools/validate_json.py -v` 验证
3. 在编辑器中按 `F5` 测试
